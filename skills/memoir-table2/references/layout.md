## 观察到的排版

原表跨双栏，caption 居中置于上方。最左是 Methods，随后四个协议列，右侧两块指标。Val Seen 与 Val Unseen 各跨六列，每组有独立的下划线。指标表头结束处有两条相邻细横线。表体使用衬线字体、紧凑的连续行，组边界画横线，整表依靠空白区分列。原表的组说明使用浅灰底和斜体，部分数值加粗。± 标准差紧随均值，以略小的字重和尺寸显示。表注紧贴底线下方。

当前项目省略协议列与跨行说明后，保留两块指标的排列、对齐和横线层次。组说明的灰色填充可以改作用户明确指定的实验行高亮，含义写在表注中。

## 可复用的尺寸起点

下列是便于重绘的起点，实际字体和长方法名决定最终宽度。

| 元素 | 建议 |
|---|---|
| 正文字体 | Times New Roman 或 Liberation Serif，可回退 STIXGeneral |
| 表体字号 | 10–11 pt，缩到论文版心后仍保持可读 |
| 组名和指标名 | 与表体接近的字号，适度加粗 |
| 标准差 | 主数值字号约 80%，同行排布 |
| 正文行高 | 字号约 1.5–1.8 倍，长方法名按需增高 |
| 两块指标间空白 | 8–12 pt |
| 顶部和底部线 | 约 0.8–1.0 pt |
| 组名下划线 | 约 0.4–0.5 pt |
| 表头底部双线 | 各约 0.4–0.5 pt，间距约 2 pt |
| 组间横线 | 约 0.4 pt |
| 高亮背景 | 浅灰，如 #F0F0F0 |
| PNG | 300 dpi，四周少量白边 |
| PDF | 矢量文字与线条，嵌入可用字体 |

TL 的下降箭头沿用原表。解释实验时结合 SR、SPL 判断更短路径的意义。单元格优胜加粗须在用户指定的可比范围内计算，保留并列值。
