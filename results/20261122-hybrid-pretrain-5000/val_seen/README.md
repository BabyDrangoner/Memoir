# 世界模型的 val_seen 预测

在相同的 1,089 个预测起点上，混合模型在 1、3、5 步均取得最高视点 Top-1 和 MRR。相对作者 Transformer，五步在终点样本上多答对 63 条，在终点前一步少答对 1 条。三步距离预测上，纯 Mamba-2 的 MAE 最低。

混合模型使用 3 层 Mamba-2 加 1 层时间因果自注意力，隐藏宽度为 768，取自第 5,000 步预训练。作者发布的 Transformer 和第 1,245 步的纯 Mamba-2 均经过 IR2R 后训练，训练阶段和架构都可能影响差异。

三组预测均使用相同的专家轨迹前缀、候选视点和采样种子。共覆盖 1,011 条指令、337 条路线、53 个场景。

模型读取指令和截至起点的真实观测，再连续想象未来。评分时，将预测的视觉特征与同一条专家路线上的各个视点做余弦相似度排序。Top-1 是目标视点排在首位的比例，MRR 是目标视点排名倒数的平均值。距离头沿用原测试的标签，取目标视点之后一个专家视点到终点的最短路径长度，到达终点后标签为零。

## 五步预测的终点构成

1,089 个五步样本中，711 个的目标视点正好是终点，378 个的目标视点还差一步到达终点。若每次都把终点排第一，五步 Top-1 就有 65.29%。这两组的距离标签均为零，五步距离 MAE 只反映距离头在终点附近的偏差。

| 目标位置 | 预测条数 | 原版 Transformer Top-1 | 纯 Mamba-2 Top-1 | 混合模型 Top-1 |
|---|---:|---:|---:|---:|
| 终点 | 711 | 64.84% | 61.74% | 73.70% |
| 终点前一步 | 378 | 35.71% | 33.60% | 35.45% |

Top-1 和 MRR 越高越好，距离 MAE 越低越好。逐场景配对重采样 5,000 次的差值区间保存在 comparison.json。

混合模型使用 Tesla T4 和 PyTorch 2.5.1+cu121。历史基线使用 Tesla T4 和 PyTorch 2.5.1+cu121。
