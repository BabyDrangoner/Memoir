# IR2R 未见场景的世界模型预测

在仍可预测五步的 2,292 个共同起点上，混合模型的一步视点命中率比作者 Transformer 高 3.32 个百分点，三步差值为 −1.48 个百分点（95% 区间跨零），五步低 6.33 个百分点。将各步可用的全部起点纳入后，作者的 1、3、5 步命中率均较高。在已见场景观察到的三步优势未在这里复现。[已见场景对照](../val_seen/README.md)

固定三份权重，在官方 `val_unseen` 的 11 个未见场景、783 条专家路线、2,349 条指令上做开环预测。每个模型先读取指令与真实前缀，再自行递推未来状态。评分以同一条专家路线上的不同视点为候选，按预测视觉特征和候选特征的余弦相似度排序。

混合模型为 3 层 Mamba-2 加 1 层因果自注意力，取自预训练第 5,000 步。作者发布的 Transformer 和第 1,245 步纯 Mamba-2 都经过 IR2R 后训练。比较描述这三份权重的预测能力。该划分用于开发验证，作者公开权重也使用过验证集选模。
